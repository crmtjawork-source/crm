# בדיקות ידניות — חיבור Google Drive

## הכנה חד-פעמית (טים)
1. ב-Google Cloud Console (אותו פרויקט של יומן גוגל): APIs & Services › Library › להפעיל **Google Drive API**.
2. OAuth consent screen › Scopes: להוסיף `.../auth/drive.file`. אם האפליקציה במצב Testing — לוודא שחשבון הגוגל של העסק ברשימת Test users.
3. אין צורך ב-Redirect URI חדש (אותו `/api/integrations/google/callback`) ואין משתני סביבה חדשים חובה.
4. *אופציונלי* — כדי שהקבצים ייכנסו לתיקייה **קיימת** בדרייב: משתנה סביבה `GOOGLE_DRIVE_FULL_SCOPE=1` ב-Vercel (הרשאת `drive` מלאה). בלי זה המערכת רואה רק תיקיות שיצרה בעצמה, ותיצור לבד תיקיית שורש "לקוחות CRM".
5. המיגרציה `supabase/migrations/20261120100000_google_drive.sql` חייבת להיות מוחלת על ה-DB.
