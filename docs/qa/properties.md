# בדיקות ידניות — נכסים והתאמת לקוחות

## תנאי מקדים
- הרצת המיגרציה `supabase/migrations/20261120100000_matching_config.sql` (עמודה `organizations.matching_config`). בלעדיה מסך ההגדרות יציג הודעה שצריך עדכון מסד נתונים.
- בארגון אינווסטד כבר נוספו: שדה "שכירות חודשית צפויה" בנכסים, שדה "יכולת תזרים שלילי חודשי" בלקוחות, וסטטוסים "ממתין להצמדה" ו"בתהליך רכישה" (הסטטוס "נמכר" כבר היה קיים).

## הנוסחה (איך קראנו את ההנחיה)
תשלום חודשי = מחיר מבוקש × 0.75 ÷ 100,000 × 525. כלומר ההלוואה (75% מהמחיר) מחולקת ל"יחידות" של 100,000 ₪, וכל יחידה עולה 525 ₪ בחודש. תזרים = שכירות − תשלום חודשי. נכס מתאים ללקוח כשהתזרים השלילי ≤ יכולת התזרים של הלקוח × 1.10. כל המספרים (75%, גודל יחידה, 525, 10%) ניתנים לעריכה בהגדרות. אם הקריאה של "יחידות" שונה (למשל יחידה = 1,000 ₪) — משנים את "גודל יחידה".

## 1. הגדרות
1. הגדרות ← "התאמת לקוחות לנכסים". צפוי: הטופס נטען עם 75% / 100,000 / 525 / 0.10.
2. בוחרים אובייקט נכסים = "נכסים", אובייקט לקוחות = "לקוחות". צפוי: רשימות השדות מתמלאות.
3. נכס: מחיר = "מחיר מבוקש", שכירות = "שכירות חודשית צפויה", אזור = "עיר", הצמדה = "מקושר ללקוח". לקוח: יכולת = "יכולת תזרים שלילי חודשי", מחיר מינ'/מקס' = "מחיר מינימלי/מקסימלי", אזור = "איזור השקעה", הון עצמי = "הון עצמי", הצמדה = "נכס משויך".
4. מסמנים כסטטוסים שלא מוצעים: "בתהליך רכישה" ו"נמכר". לוחצים שמירה. צפוי: "נשמר." ואחרי רענון ההגדרות נשארות.
5. כפתור "הוספת הסטטוסים…" על אובייקט אחר (או על מופע חדש) מוסיף את שלושת הסטטוסים החסרים בלבד, בלי כפילויות.

## 2. סטטוסי נכס
6. פותחים נכס, בסרגל השלבים בוחרים "ממתין להצמדה" ואז "בתהליך רכישה" ואז "נמכר". צפוי: כל אחד נשמר ונרשם בהיסטוריה.

## 3. הצמדה והתאמה (השתמשו ברשומות בדיקה בשם "בדיקה-…" ומחקו אחריכם)
7. יוצרים נכס "בדיקה-נכס": מחיר 1,000,000, שכירות 3,500, עיר "באר שבע", סטטוס "בשוק". צפוי: תשלום חודשי 3,937.5 ₪, תזרים שלילי 437.5 ₪.
8. יוצרים לקוחות: "בדיקה-א" יכולת 400; "בדיקה-ב" יכולת 300; "בדיקה-ג" בלי יכולת.
9. בכרטיס "בדיקה-נכס" נראה בפאנל "התאמת לקוחות": רק "בדיקה-א" (437.5 ≤ 440, מסומן "חריגה עד 9%"). "בדיקה-ב" לא מוצג; "בדיקה-ג" נספר בהודעה "לא נבדקו".
10. מעלים יכולת של "בדיקה-ב" ל-400 → מופיע גם הוא. מורידים ל-399 → עדיין נוסף? (ה-10% נותן 438.9 ≥ 437.5, כן).
11. לוחצים "הצמד" ליד "בדיקה-א". צפוי: בראש הפאנל "מוצמד ללקוח: בדיקה-א", ובכרטיס הלקוח שדה "נכס משויך" מצביע על הנכס.
12. בכרטיס הלקוח "בדיקה-א" פאנל "נכסים מתאימים" מציג את "בדיקה-נכס".
13. "ביטול הצמדה" מנקה את הקישור משני הצדדים.
14. טווח מחיר: ללקוח מקס' 900,000 → ליד הנכס מופיע תג כתום "! טווח מחיר" (עדיין מוצע, מדורג נמוך יותר). אזור שונה → תג "! אזור". הון עצמי נמוך מ-25% מהמחיר → "! הון עצמי".

## 4. החרגה
15. מעבירים את "בדיקה-נכס" ל"בתהליך רכישה". צפוי: הפאנל אומר שהנכס לא מוצע להתאמה, בלי רשימה. אותו דבר ל"נמכר".
16. בכרטיס לקוח, נכס בסטטוס כזה לא מופיע בהצעות, והפאנל מציין כמה נכסים הוחרגו.

## 5. תצוגת לוח
17. ב"נכסים" לוחצים "לוח", עוברים לדף אחר וחוזרים / מרעננים / יוצאים ונכנסים. צפוי: נשארים בלוח. חוזרים ל"רשימה" → נשמר גם כן. ההעדפה נשמרת לכל משתמש וכל אובייקט בנפרד (בדפדפן).

## 6. הרשאות
18. משתמש שאינו מנהל רואה את ההגדרות לקריאה בלבד (בלי שמירה).
