# בדיקת QA — עמוד שיתוף ללקוח (אתר לעסקה / נכס)

עמוד ציבורי, לקריאה בלבד, לכל רשומה (נכס / עסקה), בנוי מהשדות, התמונות והמסמכים שנבחרו על הרשומה עצמה (לא מדרייב).
כתובת: `https://crm-xi-orcin-81.vercel.app`. לבדיקות — ליצור רשומה בשם "בדיקה — למחיקה" ולמחוק בסוף. לא לשלוח הודעות ללקוחות אמיתיים.
