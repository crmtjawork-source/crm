# שיחה מוקלטת — תמלול וסיכום AI: החלטות ותצורה

## מה נבנה
בכרטיס הליד, אזור **"שיחה מוקלטת"**: הדבקת קישור (זום / גוגל דרייב / קישור ישיר) או העלאת קובץ ← תמלול ← סיכום + החלטות + משימות ← הערה בציר הזמן ← כפתור **"שליחה ללקוח"** שממלא את הודעת הוואטסאפ (או מייל) בלי לשלוח.

הצנרת מתקדמת בצעדים קצרים (`/api/recordings/[id]/step`), כך שאין בקשה אחת ארוכה. הדפדפן מריץ את הצעדים, ו-cron (הקיים, כל דקה) ממשיך הקלטות שננטשו. סטטוסים: fetching ← awaiting_chunks ← transcribing ← summarizing ← done | failed (עם ניסיון חוזר).

## מנוע תמלול (ממשק `SttProvider`, לכל ארגון בהגדרות)
| מנוע | מתי | הערות |
|---|---|---|
| **Soniox** (ברירת מחדל מומלצת) | עברית, שיחות ארוכות | אסינכרוני, עד 300 דק' לקובץ בלי חיתוך, מזהה דוברים. נבדק על קובץ עברי אמיתי. |
| OpenAI `gpt-4o-transcribe` | חלופה | מגבלת 25MB לבקשה: קבצים גדולים נחתכים בדפדפן ל-WAV של 8 דק' |
| Groq `whisper-large-v3` | זול ומהיר | כנ"ל |
| שרת מותאם תואם-OpenAI | למשל מודל ivrit-ai המותאם לעברית, באירוח עצמי | כתובת בסיס + מודל |
| בדיקה (mock) | בדיקת התהליך | בלי עלות |

המלצה: להתחיל ב-Soniox (המפתח כבר אצל Tim, ושימש לתמלול השיחות המיובאות) ולבדוק איכות על 2–3 שיחות אמיתיות לפני החלטה סופית.

## סיכום
Claude (`claude-sonnet-5-5`, ניתן לשינוי בהגדרות) ← JSON: סיכום, החלטות, משימות והודעת לקוח. תמלולים ארוכים מאוד מסוכמים בחלקים ואז ממוזגים.

## מקורות קישור
- **קובץ מועלה**: עובד תמיד, בלי חשבונות חיצוניים.
- **Drive**: עובד לקבצים משותפים "כל מי שיש לו קישור". קבצים פרטיים דורשים חיבור גוגל עם הרשאת Drive (לא חובר).
- **Zoom**: קישור שיתוף לא ניתן להורדה ללא API. נדרשת אפליקציית Server-to-Server OAuth ב-Zoom Marketplace (Account ID, Client ID, Secret → הגדרות ← תמלול וסיכום AI). המערכת מאתרת את ההקלטה לפי `share_url` ב-6 החודשים האחרונים ומורידה את קובץ ה-M4A. **לא נבדק מול חשבון זום אמיתי.**
- תקרת הורדה מקישור: 150MB.

## בוט שמצטרף לפגישה חיה (לא נבנה, בלי מנוי)
ממשק `MeetingBotProvider` מוכן ב-`lib/server/ai/meetingBot.ts`. ספק לדוגמה, Recall.ai: כ-$0.50 לשעת הקלטה (+$0.15 לשעה לתמלול שלהם, אנחנו לא צריכים כי יש לנו Soniox), בלי דמי מנוי חודשיים. פגישה של שעה ≈ ₪2, ואחסון חינם 7 ימים. דורש החלטה של Tim לפני חיבור (בוט נראה למשתתפים בפגישה, שיקולי פרטיות והסכמה להקלטה).

## מה צריך מ-Tim
1. להריץ את המיגרציה (ראו למטה) — אני לא מצליח להריץ מיגרציות על פרודקשן מהסשן הזה.
2. בהגדרות ← תמלול וסיכום AI: מפתח Soniox (קיים ב-`~/.config/crm/soniox-key`) ומפתח Anthropic (אין כרגע ב-Vercel).
3. אופציונלי: אפליקציית Zoom S2S; חיבור Drive פרטי.
